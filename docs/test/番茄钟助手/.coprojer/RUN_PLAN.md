## 实现默认规则（工程提案，尚未成为验证事实）

1. 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟。每自然完成 4 次专注，下一阶段为长休息，长休息后重新开始一组。
2. 阶段（专注/短休息/长休息）与运行状态（待开始/运行/暂停）分开建模。倒计时以截止时间计算，不能依赖 tick 次数累减造成后台漂移。
3. 自然完成专注才增加完成番茄数及完成专注时长。手动结束属于跳过，不伪装为完整番茄；重置不写完成记录。UI 应清楚说明语义。
4. 阶段自然结束后进入下一阶段并明显提示，下一阶段等待用户开始，避免无人操作时连续制造完成记录。手动结束同样切到下一阶段待开始。
5. 设置修改应用于下次周期；当前计时继续使用其开始时长。无效输入不能污染已保存设置。正常界面按分钟设置，自动化可通过明确测试配置使用秒数；默认产品值不可被测试配置覆盖。
6. 暂停快照在重启后仍暂停，保持剩余时间。运行中关闭后恢复为暂停，不追补应用关闭期间的虚构番茄。UI 提示恢复状态。
7. 本地存储有版本和结构校验；损坏或写入失败显示可操作提示，不静默宣称保存成功。清空历史需要用户二次确认，只清除历史；取消不改变数据。
8. 今日统计按本地日期、真实完成记录计算；最近历史倒序展示。统计口径要在使用说明中明示。
