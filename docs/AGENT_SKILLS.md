# 智能体专属技能与模型配置助手

更新日期：2026-09-28。沿用 UI 1.6 的现有组件、主题和布局。

## 职责与实例

保留任务规划、原型设计、开发、独立验证四类职责，同类可以建立多个实例。名称不决定职责；卡片展示真实职责、模型连接名、具体型号和启用的专属技能。旧实例及其项目引用不自动合并或删除。

每个实例拥有独立技能副本，包括默认基础技能。旧的共享技能绑定在启动时转换为各实例副本；原始无归属定义保留在资料文件中供恢复，但不会在运行时提供给任何实例。

## 本地导入

1. 打开“智能体”，点击目标实例卡片的“技能”。
2. 点击“导入本地技能”，选择包含 SKILL.md 的目录。支持标准 YAML 元信息 name、description，也兼容已有 skill.json 清单。
3. 检查预览中的所属实例、来源、版本、正文、文件清单和兼容性说明。
4. 点击“确认安装并启用”。取消或关闭预览不会装配技能。

导入会把包复制到应用资料目录的 agent-skills 下，保留 scripts、references、assets 等资源，忽略 .git、node_modules、.venv 和 Python 缓存。技能包不安装依赖、不执行脚本；技能的工具需求不能扩大智能体已有权限。需要更多工具时，先保存该实例的工具配置。

单文件不超过 2 MB，每包最多 160 个文件、总计 12 MB、目录深度 8 层，SKILL.md 正文最多 80000 字符。拒绝符号链接、越界路径和非法系统路径。预览有效期 15 分钟。再次导入同名技能只更新当前实例；内置技能不能被导入覆盖。

## 在线推荐和导入

同一个面板可输入公开 GitHub 技能目录地址，先预览、后确认。当前支持公开仓库，不支持私有仓库凭据和任意网站下载。推荐或手动导入都固定到 GitHub 提交版本。

填写“需要补充什么能力”，点击“联网推荐”：默认通用助手模型生成简短搜索词，搜索 skills.sh 公开索引并核对 GitHub 的真实技能正文，然后从候选中选择并解释适配理由。可为本次选择其他已保存模型；选择只作用于这次搜索，生成搜索词和排名使用同一连接快照。网页内容仅作为候选资料；推荐不会自动安装。搜索失败、无结果、无法核实正文会明确反馈；可换关键词或改用本地导入。

最近一次成功搜索的关键词、结果、时间和模型使用记录按智能体实例保存到本机。关闭面板、切换页面、重启后均会恢复，打开面板不会自动重新搜索。搜索中关闭面板不取消请求，再次打开可看到状态；失败时保留上一次成功结果。不同实例不会互相覆盖；“清空推荐记录”只清除当前实例的记录，已安装技能不受影响。

## 默认通用助手模型

尚未配置模型的百炼新用户可使用[阿里云快速导入](ALIYUN_IMPORT.md)：粘贴 Key 识别型号，登录控制台授权后扫描实际额度，预览并一键补齐未绑定的全局智能体和默认助手。该流程保留已有绑定与实例专属 Skill。

在“模型连接”（模型配置页）的“默认通用助手模型”中选择已保存连接，点击“保存默认模型”。通用助手闲聊、操作引导、Skill 搜索推荐和模型分配建议共用此默认值；三处入口均可单次切换。未设置默认时必须明确选择本次模型，不自动借用工程智能体模型。

模型连接直接使用供应商的模型 ID 作为名称，无需另外命名。新增、编辑或复用连接时填写或选择“模型标识”即可；列表和模型选择器统一显示该 ID，智能体仍可自行命名。旧连接的内部 ID、地址、密钥和绑定关系保持不变，同名连接也不会自动合并。

使用 DashScope 的 qwen3.7-flash 时，点击现有 DashScope 连接的“复用连接”，沿用其服务地址、接口协议和已保存密钥。点击“获取列表”，从供应商返回的列表填写实际模型 ID；已有配置的型号可直接选择。保存仅新增型号配置，不改动原连接与已绑定的工程模型。也支持自行填写已确认的具体 ID。

工具栏“通用助手”提供闲聊、项目状态问答和操作引导，对话保存到本机。项目会话可使用关联项目状态及已确认偏好，不装配工程实例的专属技能，也不直接执行工程任务。团队配置建议先展示预览，经确认后应用；需求讨论、原型设计、开发与验证保留现有模型绑定和项目显式选择规则。会话范围与管理见 [工程指南](ENGINEERING_GUIDE.md#通用助手与会话)。

每次请求固定连接与模型快照。结果展示供应商返回的实际型号；若供应商未返回型号，明确显示“本次请求模型”及说明，不将请求 ID 冒充已确认的服务端型号。修改默认值不改变已发出的请求。通用助手记录与默认值沿用 engineering-v1.json；旧工程、角色、Skill 和密钥保留。

## 按需使用与隔离

任务只获取当前实例已启用的技能索引（合计最多 16000 字符）。模型匹配任务后，通过 read_skill 分页加载正文或包内文本资源。运行层检查技能归属、启用状态、职责和所需工具，其他实例的技能不能通过装配或技能读取接口使用。关闭工具会停用依赖该工具的技能。

读取器固定启动时的技能正文和包版本，更新影响后续任务。二进制资源会保存，但当前 read_skill 只支持文本读取。执行记录保存技能版本、正文摘要以及实际读取事件。命令工具保持已有权限边界；该机制不是操作系统级的进程沙箱。

## 模型配置助手

在“智能体”页打开“模型配置助手”，先为每个实例选择任务能力类别：Web 开发、前端、全栈、代码理解与生成、综合问答与分析。默认值参考智能体名称与职责，可手动调整，不更改职责本身。候选只来自“模型连接”已保存的具体型号。

每次点击“一键推荐模型”都重新读取 Arena 对应类别的最新公开榜单，不复用上次推荐的数据或用旧缓存兜底。同一次请求中相同类别只读取一次，结果逐个覆盖全局智能体实例。预览展示来源、榜单日期、本次抓取时间、精确匹配情况、得分、区间、票数与参考价格；来源自身的更新频率由网站决定。

默认“能力优先”只在对应类别最高分的已接入有效候选中推荐。“分数区间重叠时参考费用”先限定与最高分候选区间重叠的型号，再从能力 / 输入价 / 输出价的 Pareto 前沿选择。两种策略都不以速度作为指标，不把 Flash、Max 等名字当成能力结论。价格缺失不按零处理；参考价是 Arena 的美元 / 百万 tokens，并非中转连接或账户实际账单。

只匹配相同型号，不自动剥离版本、推理设置、max、thinking、harness 或供应商前缀。榜单同名多项时不自动选择；初步结果、无投票、日期超过 30 天或异常的数据不参与自动推荐。某类别抓取失败、页面格式改变或当前绑定无有效匹配时，保留原绑定并说明；未上榜不等于能力差。不同类别不混合分数，综合问答 / 代码榜仅提供规划和验证的参考，不是工程成功率测评。

沿用默认通用助手或为本次单独选择建议模型，回执标明请求及服务返回的实际型号。建议模型只能在后端筛出的候选中选择；展示理由由核实到的指标生成，不展示模型自由编造的排名。没有有效证据时不调用建议模型。

“一键应用模型配置”才更新预览覆盖的全局实例绑定，保留职责、专属 Skill、项目专属实例和已有项目显式选择。配置变化或超过 15 分钟后需重新推荐；有工程任务执行时不应用。配置助手不增加第五种工程交付职责。操作截图和验证边界见[能力榜单推荐指南](MODEL_RECOMMENDATIONS.md)。

公共榜单请求只发送固定 Arena 页面地址；模型连接密钥、服务地址和任务偏好不会发到榜单网站。

## 验证

- scripts/model-evidence.cjs：精确版本、分类与完整表格校验、未知价格、区间 / Pareto、重复型号、来源失败 / 过期、每次重新抓取。加 --live 可只读验证真实公开网站，不调用用户模型。
- scripts/model-assistant-smoke.cjs：真实隔离 Electron、五类能力选项、逐实例预览、第二次推荐读取变化后的分数、单次建议模型回执、确认应用、离线不复用旧数据、重启 / Skill 保留、双尺寸明暗与最大化截图。榜单及模型回复为受控测试数据。

- scripts/agent-skills.cjs：标准目录、YAML、资源快照、旧绑定迁移、归属隔离、启用状态、确认安装、取消、重启保留、模型分配、过期与虚构结果拒绝。
- scripts/agent-configuration-smoke.cjs：隔离资料目录中的真实 Electron 交互；本地预览/安装、联网推荐与安装、模型预览/应用、真实 read_skill 工具往返，以及 1280×840 / 860×600 布局。模型与在线服务使用受控测试响应，不代表真实模型推荐质量。
- npm test 包含以上检查与原有工程流程回归。截图位于 output/playwright/agent-skills/。
- scripts/general-assistant.cjs：默认/单次路由、请求快照、服务返回型号、历史与重启、推荐按实例保留、失败保留旧结果、无结果与主动清空、原配置保留。
- scripts/general-assistant-smoke.cjs：隔离 Electron 中的连接复用、默认值、三处单次切换、实际型号显示、搜索中关闭/重开/重启、实例隔离、工程任务路由和双尺寸明暗主题。供应商与在线服务为受控协议响应，不能代替真实 DashScope 凭据和型号可用性验证。
