# 使用指南

[项目首页](../README.md) · [文档索引](README.md) · [番茄钟流程示例](examples/pomodoro.md)

Coprojer 将需求讨论、原型、开发、验证与验收组织在同一个项目中。本指南说明首次配置和日常使用；完整操作示例见[番茄钟助手](examples/pomodoro.md)。

## 安装与启动

从 [Releases](https://github.com/yuyanpeng0909-cmyk/coprojer/releases/latest) 下载 Windows x64 安装包，按向导安装后打开 Coprojer。安装说明、签名状态和校验信息以发布页为准。

- 打开桌面界面无需克隆源码。
- 执行工程开发命令需要 Node.js 22.12+ 与 npm。
- 工程开发需要有效的模型连接，调用费用由接入的服务决定。

## 首次创建与模型配置

### 连接模型

打开「新手入门」或「模型连接」，新增一个模型，填写服务地址、协议、API Key 与型号。支持 Chat Completions、Responses 和 Anthropic Messages；型号可以获取列表或手动填写。

先「测试连接」，再「检查开发能力」，分别确认普通回复与工具往返。将可用模型分配给规划、原型、开发、测试校验四类角色；一个型号可以用于多个角色。默认通用助手用于答疑，工程角色使用各自的绑定。

![模型连接与能力检查](screenshots/pomodoro/17a-model-setup.png)

阿里云百炼用户也可使用[快速导入](ALIYUN_IMPORT.md)。模型推荐、实例推理参数与专属技能可在基本配置完成后按需设置。

### 创建或打开项目

在项目库选择已有项目，或通过「新建项目」填写名称、父目录和目标。新建操作会检查环境与目录，并使用新的子目录。已有项目可从项目库继续。

建议把第一次练习放在独立目录。可以从[番茄钟示例](../examples/pomodoro/README.md)学习代码和测试，再在自己的项目中复现开发流程。

## 从需求到验收

| 阶段 | 你的操作 | 形成的内容 |
| --- | --- | --- |
| 需求讨论 | 描述使用场景、范围和限制，回答关键取舍 | 讨论记录、功能图和待确认需求 |
| 交互原型 | 试用界面并提出修改意见 | 原型版本与设计反馈 |
| 需求确认 | 核对功能范围、规格和验收条件 | 后续开发使用的需求基线 |
| 方案审阅 | 查看实现方案、依赖与执行顺序，确认开工 | 功能方案与开发队列 |
| 开发与验证 | 查看实际改动、命令和独立验证结果 | 代码修改、测试记录与待处理问题 |
| 成果验收 | 启动成果，逐项试用并接受或反馈 | 人工验收结果与后续任务 |

需求、方案和最终成果由你确认。可先完成一项小功能，再继续后面的队列。完整说明见[工程指南](ENGINEERING_GUIDE.md)。

### 查看与调整原型

在「原型设计」查看反馈和版本，打开独立窗口试用。验收原型后核对提取的需求与功能；原型用于明确交互，最终效果仍要在实际程序中检查。没有界面的后台或设备项目按对应功能流程推进。

![原型版本与预览入口](screenshots/pomodoro/04-prototype-panel.png)

### 检查开发结果

进入执行记录查看文件修改、命令输出和错误信息，在独立验证中核对各项验收条件。存在失败或缺少证据时，按界面提示修复或补充验证条件。

![实际文件修改对照](screenshots/pomodoro/12-code-changes.png)

内置预览用于 HTTP 网页工程；原生桌面应用按目标工程的运行说明启动。启动后亲自检查关键交互，再提交验收。

### 中断后继续

需要暂停时使用停止操作，稍后从项目库或当前功能继续。应用保留已有阶段和执行记录；恢复前核对当前需求、方案及待验证事项，避免把旧结果直接用于已经修改的代码。

## 项目、模型与资料管理

- **项目库**：搜索、排序、置顶、归档和恢复项目。归档用于整理列表。
- **共享上下文**：管理需求、规范和补充资料，查看角色实际取材。
- **模型与智能体**：管理连接、角色、实例参数和专属技能。
- **模型监控**：按连接查看请求、Token、失败率与耗时；用量口径见[监控说明](MODEL_TRAFFIC.md)。
- **通用助手**：在项目或全局会话中提问，预览并确认需要应用的配置建议。

应用资料保存在本机，模型调用会将相关上下文发送给配置的服务。正式版与开发版使用不同资料目录；具体位置、隔离验证和导出文件说明见[开发指南](DEVELOPMENT.md#本地资料与隔离验证)。
