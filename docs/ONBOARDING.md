# 新手入门

更新：2026-09-28。侧栏「项目管理」下方的「新手入门」随时可打开，首页进度卡可以收起。引导使用真实工程状态，不创建演示工程。

已有项目的老用户及已完成配置准备的用户默认看到紧凑进度卡，保留首页继续开发的空间；手动展开或收起后优先保留个人选择。

## 使用准备

1. 接入第一个模型。可以手动填写地址、协议、Key 和型号，也可以使用阿里云快速导入。导入已经完成的绑定会被直接识别。
2. 设置默认通用助手，并测试连接。助手用于答疑和配置建议；工程成员继续使用自己的模型。
3. 检查规划、原型前端、开发、测试校验四类成员的模型和必要工具，点击「检查开发能力」。一个型号可以用于多类成员，只需检查同一连接一次。榜单推荐、技能安装和自定义团队是可选进阶项。

引导本身不依赖模型。浏览、跳转、暂停和恢复不会发起模型调用；测试连接、能力检查以及实际工程操作由用户主动点击，可能按连接服务的规则计费。

## 第一次开发

选择自己的已有项目，或点击「新建入门项目」。从入门页新建的工程会自动成为跟随项目；普通工作台项目切换不会改变它。生成本期功能后，默认跟随第一项，也可以手动选择另一项。

按真实流程完成：描述想法 → 试用并验收原型 → 确认需求与规格 → 审阅方案和确认开工 → 开发 → 独立验证 → 亲自试用并验收。

- 当前页说明解释要做什么、为什么，以及完成后会发生什么。「定位操作」只导航、定位已有控件，不自动创建、批准或启动任务。
- 「稍后继续」暂停逐页提示；「继续引导」或「恢复逐页说明」可以恢复。单独收起说明和首页卡片也会保存。
- 项目、功能、暂停和收起状态保存在本机工程资料中，重启后恢复。应用仍从项目管理启动。
- 完成状态从实际记录推导，浏览某页不算完成。独立验证通过不等于人工验收；待补验证、失败、其它项目或其它功能的完成记录不会被用来凑齐进度。
- 项目归档、功能移出本期或配置失效时提示重新选择或修复，保留原工程。只含后台/设备的项目没有界面原型步骤。

## 测试记录

「已保存」「连接已测试」「开发能力检查通过」分别显示。主进程记录检查类型、通过/失败和时间，保存前已做的测试也会在保存匹配连接时保留。记录不包含 Key、模型回复或凭据摘要。修改地址、协议、型号或 Key 后，旧连接的记录不会验证新配置；旧请求的迟到响应不会覆盖新配置。测试记录表示最近一次检查结果，不保证服务永久在线或模型适用于所有任务。

## 验证

运行 npm run test:onboarding：构建、状态/失效单元检查，以及隔离 Electron 交互。测试只连接本地受控模型服务，不使用用户真实 Key。

scripts/onboarding.cjs 覆盖配置变化、重启记录、迟到结果、保存失败、项目/功能隔离、过期需求基线和人工验收边界；scripts/onboarding-smoke.cjs 覆盖无模型入口、配置/测试、创建真实目录、阶段导航、暂停与重启、错误恢复和 1280 × 840 / 860 × 600 明暗主题。运行结果保存在 output/playwright/onboarding/verification.json。
