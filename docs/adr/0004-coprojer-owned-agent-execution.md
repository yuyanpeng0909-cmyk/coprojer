# Coprojer 直接调用模型并组织工程工具执行

为统一管理功能开发流程与执行记录，第一期由 Coprojer 直接调用用户配置的模型服务，将智能体职责与工程共享上下文交给模型，并提供文件读写、命令执行和测试等工程工具。模型调用与工具操作的过程、结果关联到对应功能记录。

用户随后明确要求提供通用「新增模型」入口，自行配置模型服务与模型并测试连接。供应商协议适配是实现职责，不以用户逐家提供接口文档为产品设计的前置条件。

这使工具执行能力及其运行管理成为 Coprojer 需要实现和维护的产品能力。具体协议适配、SDK、凭据存储和工具权限细节尚未确定；本决策不代表这些能力已在当前代码中实现。
