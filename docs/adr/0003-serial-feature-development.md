# 第一期按功能串行开发

在讨论并行代码隔离与集成方案时，用户将决定改为「算了。就功能串行开发吧」。因此第一期同一项目按功能逐项推进代码实现与验证，本决策取代 [ADR 0002](0002-parallel-delivery-from-first-release.md) 的并行要求；尚未采纳的并行工作区与自动集成方案一并撤回。

每项功能仍由开发与验证两个角色接力，保留既有的三个人工节点、默认最多 3 轮自动修复以及从零创建项目的首测路线。此处只改变功能之间的开发方式；等待人工验收或异常暂停时的队列处理、底层代码隔离技术与跨项目调度尚未确定。
